Tesla Bar

A private, read-only Omarchy desktop widget for battery level and last known vehicle location.

This static site hosts the application's public key and its authorization callback. It does not provide a vehicle dashboard, store vehicle data or offer remote commands.

OAuth tokens and the private key remain on the owner's laptop. No analytics or third-party scripts are embedded. The hosting provider may retain ordinary HTTP access logs, including a short-lived authorization code in a callback request.
